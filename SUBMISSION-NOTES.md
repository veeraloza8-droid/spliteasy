# Before you submit SplitEasy to Stardance

- Confirm you personally tested the version in `index.html`, including **Create group**, **Save expense**, and **Mark paid**, in a real Chrome/Edge browser.
- Upload the root files to a **public GitHub repository** named `spliteasy`.
- From GitHub **Settings → Pages**, choose **Deploy from a branch → main → /(root)**. Wait for the live `https://USERNAME.github.io/spliteasy/` URL. Test it in a private/incognito window.
- Replace the **Live demo** placeholder in README.md with the actual URL and commit the update.
- On https://stardance.hackclub.com/ create a **custom software/web app project** called **SplitEasy**.
- Connect **Hackatime** to the project and use an editor plugin to record your own real coding activity. Do not invent hours; AI generation and waiting time should not be claimed as your coding time.
- Post a **truthful devlog** of what you actually did. Mention the group's create-button bug, the interface redesign, your own testing, and any changes you personally coded. Disclose ChatGPT assistance.
- Add at least one screenshot, a concise project description, the public repository URL, and the live demo URL, then choose **Ship** once each item is complete.
- If your account eligibility or AI-assistance rules are uncertain, ask the #stardance-help channel before shipping.

Suggested short project description (edit in your own words):

> SplitEasy is a browser-based group expense tracker. Add your friends and shared expenses, and it calculates who owes whom. Record repayments, export your data, and use it without accounts or subscriptions.

Suggested devlog topics (write only what you actually did):

1. What user problem you chose to solve and why.
2. What went wrong in the first version, and how you tested the fix.
3. How the final version calculates equal splits and payments.
4. What you'd improve next and what AI assistance was used.
